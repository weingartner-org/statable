# Name und Logo

Der Code steht unter der GNU GPL v3. **Der Name „Statable" und das Logo
stehen nicht darunter.**

Sie dürfen den Code benutzen, ändern und weitergeben, wie die GPL es erlaubt.
Eine veränderte Fassung geben Sie bitte unter einem eigenen Namen und ohne
unser Logo heraus. Sagen dürfen Sie: „beruht auf Statable".

Die GPL v3 sieht diese Bedingung ausdrücklich vor (§ 7 e: Markenrechte dürfen
vorbehalten werden).
